# Codveda Technology - Data Analytics Internship

Welcome to my GitHub repository showcasing the projects and tasks completed during my **Data Analytics Internship** at **[Codveda Technology](https://www.codveda.com)**. This 1-month program focuses on progressive learning through structured, practical tasks spanning data preprocessing, statistical modeling, machine learning, and business intelligence.

---

## Project Structure & Roadmap

The internship curriculum is divided into three distinct difficulty levels. To fulfill the internship requirements, a minimum of **two tasks per level** were selected and successfully implemented.

### Level 1: Basic (Data Exploration & Cleaning)
*   **[ ] Task 1: Data Cleaning and Preprocessing**
    *   *Objectives:* Loading raw datasets, treating missing values via imputation/removal, deduplication, and standardizing formatting inconsistencies using `pandas`.
*   **[ ] Task 2: Exploratory Data Analysis (EDA)**
    *   *Objectives:* Computing descriptive statistics (mean, median, mode, standard deviation) and engineering visualizations (histograms, boxplots, scatter plots, correlation matrices).
*   **[ ] Task 3: Basic Data Visualization**
    *   *Objectives:* Crafting customized bar plots, line charts, and scatter plots with tailored legends and labels, followed by asset exporting.

### Level 2: Intermediate (Statistical & Predictive Analysis)
*   **[ ] Task 1: Regression Analysis**
    *   *Objectives:* Splitting data into train/test subsets, fitting a Linear Regression model via `scikit-learn`, and evaluating via $R^2$ and Mean Squared Error (MSE).
*   **[ ] Task 2: Time Series Analysis**
    *   *Objectives:* Extracting trend, seasonality, and residual patterns via `statsmodels` decomposition and applying moving average smoothing.
*   **[ ] Task 3: Clustering Analysis (K-Means)**
    *   *Objectives:* Data standardization using `StandardScaler`, identifying optimal clusters via the Elbow Method, and map rendering in 2D space.

### Level 3: Advanced (Machine Learning & Business Intelligence)
*   **[ ] Task 1: Predictive Modeling (Classification)**
    *   *Objectives:* Training classification models (Logistic Regression, Decision Trees, Random Forests), utilizing Grid Search hyperparameter tuning, and analyzing performance (F1-score, Precision, Recall).
*   **[ ] Task 2: Building Dashboards with Power BI / Tableau**
    *   *Objectives:* Transforming raw data into fully interactive executive dashboards featuring slicers, operational filters, and geospatial/trend mappings.
*   **[ ] Task 3: NLP - Sentiment Analysis**
    *   *Objectives:* NLP text parsing (tokenization, stopword removal, lemmatization) using `nltk`/`TextBlob` paired with semantic word clouds.
